# flowshekan
# تحریم شکن فلو

ابزار دور زدن تحریم و محدودیت منطقه‌ای سرویس Google Flow.

> تقدیم به تمام ایرانی‌هایی که هیچ دری به روشون بسته نمیمونه.

## ویژگی‌ها
- اتصال مستقیم به Google Flow بدون نیاز به تغییر ریجن سیستم یا مرورگر
- عملکرد کلاینت‌محور (Client-Side Interception) بدون افت سرعت ترافیک

## راه‌اندازی در Chrome
1. این پوشه را در سیستم خود ذخیره کنید.
2. در مرورگر به آدرس `chrome://extensions` بروید.
3. گزینه **Developer mode** را از گوشه بالا فعال کنید.
4. روی دکمه **Load unpacked** کلیک کرده و این پوشه را انتخاب کنید.
5. از طریق آیکون افزونه، سوئیچ دسترسی را فعال کرده و وارد Google Flow شوید.
